# Featured

This folder holds the small handful of pieces shown in the featured strip on the homepage — your absolute best work, the first art a visitor sees after the hero drawing.

## What goes here

- **3 to 6 pieces.** More than that dilutes the strip; the homepage isn't the gallery.
- These can be copies of files that also live in `gallery/` — that's fine and expected. Keeping a copy here makes it obvious which pieces are the showcase set.

## File naming

Lowercase, hyphens instead of spaces, e.g. `ascension-final.jpg`. You'll reference these filenames from `content/site.ts` (the homepage settings), so keep them short and recognizable.

## Format & size guidance

- **JPG** (quality ~85–90%) for painted work, **PNG** for crisp line art.
- **Dimensions:** 1600–2000 px on the longest side. These display large, so don't go below ~1200 px.
- **File size target:** under 600 KB each — the homepage should load fast.

## Adult content

Avoid putting adult pieces in the featured strip — it's the first thing every visitor sees, before any age gate or blur can do its job. If you do feature one anyway, its entry must be marked `nsfw: true` like everywhere else.
