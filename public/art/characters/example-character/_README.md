# Example Character (template folder)

This is a template showing how each character's folder should look. Copy this structure for every real character, using the character's name (lowercase, hyphens for spaces) as the folder name. Delete this example folder once you have real character folders.

## Suggested files

| File | What it is |
|---|---|
| `ref-sheet.png` or `ref-sheet.jpg` | The main reference sheet — the image shown first on the character's page. |
| `portrait.jpg` | A face/bust shot, used as the character's thumbnail. |
| `expressions.jpg` | Expression sheet (optional). |
| `outfit-<name>.jpg` | One file per outfit or costume variant (optional). |
| anything else | Supporting art, older pieces, turnarounds — name them clearly. |

These names are suggestions, not requirements — but whatever names you use are what you'll type into that character's entry in `content/characters.ts`.

## Format & size guidance

- **JPG** for painted/shaded work, **PNG** for line art or anything needing transparency.
- Reference sheets are usually wide: up to **2400 px** on the long side is fine.
- Portraits/thumbnails: **800–1200 px** is plenty.
- Keep each file under ~800 KB.

## Adult content

Adult reference material can live here, but the character's entry (or the specific image's entry) in `content/characters.ts` must be marked `nsfw: true`.
