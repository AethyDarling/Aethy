# Gallery

This folder holds every finished work and study that appears in the main gallery page of the site.

## What goes here

- Finished illustrations
- Anatomy studies, figure studies, sketchbook pages you're happy to show
- Anything you want browsable in the main gallery grid

## File naming

Use short, lowercase names with hyphens instead of spaces, e.g.:

- `torso-study-03.jpg`
- `winged-figure-final.png`

Whatever filename you use here is the filename you'll type into `content/gallery.ts` when you write that piece's entry (title, description, tags, etc.). Every image in this folder needs a matching entry there, or it won't show up on the site.

## Format & size guidance

- **JPG** for full-color painted work (quality ~80–90%). Best size-to-quality for paintings.
- **PNG** only when you need transparency or the piece is crisp line art (JPG smears clean lines).
- **Dimensions:** 1600–2400 px on the longest side. Bigger than 2400 px just slows the page down; smaller than ~1200 px looks soft on large screens.
- **File size target:** under 800 KB per image, ideally 300–500 KB. If a JPG export comes out larger, lower the quality slider a notch.
- Don't upload print-resolution originals here — keep those safe elsewhere.

## Adult content

Adult pieces can live in this folder like any other file — but you MUST mark their entry in `content/gallery.ts` with `nsfw: true` so the site can blur/gate them.
